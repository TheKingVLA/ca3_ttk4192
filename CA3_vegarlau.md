#### Runge-Kutta 4
Runge-Kutta 4 (RK4) is a numerical method for solving ODEs by estimating the solution to an initial value problem at successive steps. It calculates the next value 
by taking a weighted average of four slope estimates $(k_1,k_2,k_3,k_4)$ across the interval, offering a high-order error reduction.

It is defined as:
$$
\begin{aligned}
& k_1 = f(t_n, y_n), \\
& k_2 = f(t_n+\frac{dt}{2}, y_n+dt*\frac{k_1}{2}), \\
& k_3 = f(t_n+\frac{dt}{2}, y_n+dt*\frac{k_2}{2}), \\
& k_4 = f(t_n+dt, y_n+dt*k_3)
\end{aligned}
$$
With update:
$$
\begin{aligned}
& y_{n+1}=y_n+\frac{dt}{6}(k_1+2k_2+2k_3+k_4) \\
& t_{n+1}=t_n+dt
\end{aligned}
$$

#### Multible-shooting
The multiple-shooting method is a numerical technique for solving boundary value problems (BVPs) and optimal control problems by dividing a large time interval into smaller, manageable segments. It solves an initial value problem (IVP) within each segment, ensuring continuity between segments via matching conditions, thus transforming the problem into a, often more stable, nonlinear programming problem.

It partitions the interval $[t_a, t_b]$ by introducing additional grid points:
$$ t_a= t_0<t_1<\cdots<t_N=t_b$$

Then, on each subinterval $[t_i,t_{i+1}]$, the system is solved as an initial value problem with its own initial state:
$$\dot{x}=f(x(t),u(t),t), x(t_i)=s_i$$
Here,$s_i$ are additional decision variables called shooting nodes. After integrating each segment, continuity constraints are imposed to ensure that the end of one segment matches the start of the next:
$$x_i (t_{i+1};s_i)-s{i+1}=0, i=0,\dots,N-1$$
This converts the original boundary value or optimal control problem into a finite-dimensional nonlinear optimization problem where the segment states (and possibly controls) are optimized while enforcing continuity across the intervals.
